# 第三问 Pro 分析交接

本目录用于让 Pro 参考相关论文，独立审查并实际求解第三问，最终交付时长、表5、`result3.xlsx` 和可复现代码。**本目录是预分析交接，不是第三问最终答案；没有生成正式 result3.xlsx。**

## 使用

复制 [简短启动提示词](发给Pro的简短提示词.txt)，让 Pro 主动从 [GitHub仓库](https://github.com/Hel10o/libai) 读取 [主交付说明](第三问分析与Pro交付说明.md) 和所需资料。若二进制读取受限，可上传根目录的 `第三问_Pro分析交付包.zip`，其中保留项目相对路径和同哈希输入副本。

主说明给出工作基线、合理对照及验收要求，最终假设选择仍需 Pro 给出证据。所有先导时长都不应成为拟合目标。不能只返回计划或未运行的代码。

## 本轮发现与材料

- 原始环境只覆盖前4h，长期时长需要明确未来环境假设，并比较末值、末段均值与名义平台。
- 第三问判定的是全域最大含水率严格低于0.15；临界等式根、严格合格时间和第一个合格整分钟是不同概念。
- 真实长时先导显示原通量在粗网格上的时长差异很大；积分通量对照收敛较快，但本轮尚未认证最终四位时长或完成独立长期与二维验收。
- 论文的边界量、热量方程和扩散系数形式应逐项核对，方法参考不等于参数或精度可以迁移。

## ZIP的范围和复现

ZIP包含本目录、第三问原始输入、第二问核心源代码与部分已验收结果/记录，以及所引用论文的现有逐页可读文本；它不是整个仓库的备份。原论文PDF按可读索引回到仓库取得，关键公式需回看原PDF。不要把选入的历史报告所链接的其他未打包材料称为本包齐备。

先导脚本从解压后的项目根目录运行，具体命令和来源见先导说明。部分历史第二问运行入口需要完整原交付；如要重跑第二问全套验证，回到GitHub取得完整目录，不能把本ZIP误作全套第二问复现包。

原始输入、前两问交付与审核记录保持不变。本目录和交接ZIP随本轮项目更新同步GitHub。请记录实际提交；后续材料有变化时按清单和原始文件哈希区分版本。
