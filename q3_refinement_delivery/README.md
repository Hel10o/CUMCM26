# q3_refinement_delivery

本目录是第三问定向复审后的新交付，不覆盖历史 `q3_final_delivery/`。本轮读取仓库提交 `c1743f6b19d7f357d1bc005310fdb6367a549bec`，针对 206901 s 比较、8 处四位舍入敏感值、自动结束时间和只读验证等问题完成修订。

主口径仍为：前4h使用附件1分段线性环境，之后保持末1h的61个观测点算术均值；固定半径2cm、长度25cm；附录3变物性；轴向均匀一维径向模型；以完整域最大干基含水率严格小于0.15为结束判据。

临界根为 **206906.389932345570 s = 57.4739972034 h**，四位小时为 **57.4740 h**。临界根是等号状态，不满足严格不等号。按0.03s工程数值预算并向上量化到0.0001h后，正式执行端点为 **206906.76 s = 57.4741 h**，端点最大含水率为 **0.14999989220803223 kg/kg**。

正式 `output/result3.xlsx` 共有 3449 行数据、72429 个水分数值单元格，全部来自同一未舍入配置法轨迹。历史有限体积解中8个跨四位舍入分界的单元格已由统一轨迹重导出；N=160 BDF与本轮新跑N=80 BDF对照均实现全表四位 **0** 个差异。

## 运行入口

```bash
python run_all.py verify --audit-out /path/to/new_audit
python run_all.py scenario --name nominal --out /path/to/new_nominal.json
python run_all.py cold-start --out /path/to/new_solution_prefix
```

`verify` 只读冻结目录，检查结果必须写到新审核目录。`cold-start` 会重新积分，耗时显著高于只读验收；已有正式文件不会被覆盖。
