## 阅读与编辑

- `第一问论文阶段稿.pdf`：编译后的阅读稿。
- `main.tex`：摘要和文档入口。
- `sections/preliminaries.tex`：问题重述、假设与符号。
- `sections/q1_model.tex`：模型、求解与数值验证。
- `sections/q1_results.tex`：第一问结果与尺度分析。
- `sections/q1_limits.tex`：敏感性与物理适用边界。
- `figures/`、`tables/`：由正式数值结果生成的图表。
- `evidence/`：数字来源、图表生成清单、阶段使用记录与验收说明。
- `validate_paper.py`：从实际 PDF 提取两张结果表，并检查正式源文件哈希和编译状态；依赖 `pypdf` 与 Poppler 的 `pdftotext`。

在项目根目录执行：

```powershell
& .\paper\build.ps1
```

需要重新生成图表时执行 `& .\paper\build.ps1 -RefreshAssets`。构建使用现有 XeLaTeX/latexmk；图表脚本使用项目审核虚拟环境中的 NumPy、Matplotlib，直接读取已冻结的结果，不重新求解 PDE。若原始数据或模型变化，应先完成求解及独立验证，再统一刷新正文数字和图表；构建脚本不会自动将所有叙述数字替换为新结果。
