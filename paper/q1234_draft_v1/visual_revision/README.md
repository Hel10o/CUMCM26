# 六图重绘与正文联动

本目录只作冻结数据的绘图后处理，基线提交为 `a2c8baf0175c29a4fe21145ba222cb8e19d84199`。不导入求解器，不计算新的 PDE 状态、临界根或参数情景。现行正文引用 `../figures/visual_revision/` 下的 PDF；旧图和旧资产脚本作为历史保留。

| 图 | 呈现方式 | 数据与显示处理 | 正文联动 |
|---|---|---|---|
| 1 | 时间—径向温湿色图 | 第一问全部已存逐秒、径向采样，最近单元着色；两侧色标对应不同物理量 | 说明横向跟踪时间、纵向比较位置；原温差、含水率、扩散尺度分析保留 |
| 2 | 温湿状态路径＋含水率径向剖面 | 第二问前 3 h 每 15 s 取已存状态，箭头连接已存时刻；右图从原六个时刻中选取三个含水率剖面 | 说明路径不是时间横轴；径向梯度论证由右图和原六时刻规定表支撑 |
| 3 | 全过程曲线＋离散事件时间标尺 | 第三问每 60 s 取已存点并保留正式末点，第四问用全部已存点；等号根、执行点与最大值读自原 JSON | 区分过程与事件标尺；保留两问物性不同的解释 |
| 4 | 实际收缩材料域色图＋剖面＋观测小图 | 按 `r=R(t)*sqrt(x)` 映射已有场，Gouraud 仅作网格内颜色插值；色图止于执行点，域外不填色；完整观测历程单独保留 | 说明当前半径、对数色标、域外留白及三个面板的时间范围 |
| 5 | 中截面终点差值＋整根终点配对均值 | 六份冻结配对数组，完整 81 节点、半柱 `z=0`；按原权重算均值，仅作差和加权汇总 | 终点差值与时窗最大差分开；失水增加不是平均含水率相对误差，各行不同时窗不作排名 |
| 6 | 共零线的情景点图 | 已存情景根减同阶基线；只画已有八个差值 | 说明正负方向、问别点形及人工幅度；不作误差条或置信区间 |
