# 问题二前 3 h 温度与含水率场图

`q2_fields.pdf/svg/png` 为 2026-09-13 新版图5，参考用户 Word 中图7-2的双热图结构，替换旧版温湿状态路径与径向剖面组合。旧图和历史数值文件不覆盖。

图形尺寸保持原图的 **16.4 × 8.1 cm**。左右图统一采用时间 `t / h` 为横轴（0—3 h）、径向位置 `r / cm` 为纵轴（0—2 cm），分别显示温度与干基含水率，各有独立色标。温度采用 `YlOrBr` 顺序色图，含水率采用 `YlGnBu` 顺序色图；少量等值线标明数值，轴心、表面及末时差值有明确标记。

数据来自 `q4_complete_delivery/v1/q123_closeout/output/q23_unified.npz` 中的 `time_s`、`radius_cm`、`profile_TC`。保留前 10800 s 的全部 **10801 个逐秒时刻**和 **21 个原始径向节点**。仅为显示，在每个保存时刻沿径向作线性插值，形成101个显示节点；原有21节点值逐项完全相同。未做时间插值、平滑或重新求解。热图以600 dpi栅格化，文字、坐标及等值线保留矢量。

等值线由 Matplotlib 在原始采样网格内插值得到，仅辅助阅读，不是连续域阈值的严格边界。图中 3 h 轴心/表面温度为 **49.8495 / 49.9664 °C**，含水率为 **1.7662 / 1.0081 kg/kg**，末时差值 **0.1169 K / 0.7581 kg/kg** 与现稿相同。

中文宋体，英文及数字 Times New Roman。源图子图标题11.5 pt、轴及单位10.8 pt、末时注释10.6 pt、刻度及等值线标注10.2 pt；按正文14.1 cm宽插入时，最小字号约8.77 pt。
