# 问题三流程图白底版

本目录仅将上一版流程图的七个彩色填充改为白色；文字、字体、字号、框位置和尺寸、六条箭头及其颜色均保持。原彩色图留在 `../q3_intro/`。

画布15×3.2 cm，宋体/Times New Roman，字号10 pt，行距系数1.18。当前正文图7使用本目录PDF，PNG为600 dpi预览。

重绘：在论文目录运行 `python -X utf8 build_q3_white.py`。该脚本只读取既有论文文字及绘图模板，不读取数值数组或运行求解。

来源、节点与字体记录见 `../../evidence/q3_white_20260913/workflow_sources.json`；PDF绘图命令逐项核对确认仅七个填充改变，见同目录 `fill_only_check.json`。
