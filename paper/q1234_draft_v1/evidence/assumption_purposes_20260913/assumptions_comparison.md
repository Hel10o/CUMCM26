# 模型假设与目的新旧对照

## 修改前

```tex
\section{模型假设}
\begin{enumerate}
\item \textbf{药材近似轴对称连续介质：}初始温度和含水率均匀，分问物性在当前位置按局部状态取值。主径向模型忽略端面，二维验证包含侧面和端面交换。
\item \textbf{采用干基含水率与有效湿度边界：}材料干基含水率为$C=m_w/m_d$。附件空气量记为$y_a$，表面采用有效映射$b=g(y_a,T_s,\ldots)$；现行计算取$g(y_a,\ldots)=y_a$。它是未经材料标定的恒等映射，不能把$b$直接称为实测药材平衡含水率。
\item \textbf{各问沿用题给表面交换系数：}换热、传质系数取$h_T=25\unit{W/(m^2K)}$、$h_m=8\times10^{-7}\unit{m/s}$。题面在附录2给出两系数，后问未另给时沿用该值；$h_m$属于材料干基驱动力标度，不自动等于气相浓度模型中的气膜系数。
\item \textbf{有效热容量与真实干质量分别处理：}题给$\rho c_p$用于有效热容量，记为$\rhoe c_p$；真实干质量另由$\rhod$账本描述。不同时强制$\rho/(1+C)$为真实干密度。本模型无显式蒸发潜热、液态扩散携焓和机械功项，不能据有效热方程宣称真实能量闭合。

\Needspace{4\baselineskip}
\item \textbf{前三问固定几何，第四问均匀径向收缩：}前三问干骨架静止；第四问取长度$L=L_0$，边界按附件2给定。内部仿射运动是额外假设，单凭外半径不能唯一识别。
\item \textbf{观测结束后保持末小时平均环境：}4\unit{h}后采用末小时61点的算术均值，即
\begin{equation}
T_a=49.9989344262\celsius,\qquad b=0.04998754098\unit{kg/kg}.
\label{eq:future}
\end{equation}
这是观测范围外的环境延拓假设；使用其他后段工况会形成不同情景，不因某情景更接近通常2--3天而选择其参数。
\end{enumerate}

\Needspace{22\baselineskip}
```

## 本轮试排

```tex
\section{模型假设}
\begin{enumerate}
\item \textbf{药材近似为初始温湿均匀的轴对称连续介质，主模型忽略端面：}将内部状态简化为径向温度与含水率场，减少空间变量并明确初始条件。分问物性按局部状态取值，二维验证包含侧面和端面交换。
\item \textbf{空气记录通过恒等映射给出有效湿度边界：}将附件空气量$y_a$接入表面水分交换条件，为干基含水率$C=m_w/m_d$的扩散方程提供边界输入。取$b=g(y_a,T_s,\ldots)$，现行计算取$g(y_a,\ldots)=y_a$。它是未经材料标定的恒等映射，不能把$b$直接称为实测药材平衡含水率。
```
