### 3.3 推荐版式

继续保留左右双面板：

- `(a)` 温度径向分布；
- `(b)` 干基含水率径向分布。

不建议增加第三面板，以免问题一占用过多篇幅。将证据直接标注在 1800 s 曲线上：

### 3.4 权威数据接口

必须读取与本稿版本绑定的 `result1.xlsx` 或对应未舍入数组。至少核对：

### 3.5 Python 实现要点

```python
# 仅为绘图结构示例；sheet、列名和路径必须按绑定数据调整。
times = [300, 600, 1200, 1800]
styles = ["-", "--", "-.", ":"]
colors = ["#56B4E9", "#009E73", "#E69F00", "#CC79A7"]

for t, ls, color in zip(times, styles, colors):
    part = data[data["time_s"] == t]
    ax.plot(part["r_cm"], part["temperature_C"],
            color=color, ls=ls, lw=2.0 if t == 1800 else 1.4,
            label=f"{t} s")
```

禁止用生成式图像工具修补曲线、补采样点或改变数值形状。

每幅正式图都形成以下证据单元：


1. 画的是什么；

```python
def sha256(path):
    h = hashlib.sha256()
    with Path(path).open("rb") as f:
        for chunk in iter(lambda: f.read(1024 * 1024), b""):
            h.update(chunk)
    return h.hexdigest()

def export_figure(fig, stem):
    stem = Path(stem)
    fig.savefig(stem.with_suffix(".pdf"), bbox_inches="tight")
    fig.savefig(stem.with_suffix(".svg"), bbox_inches="tight")
    fig.savefig(stem.with_suffix(".png"), dpi=600, bbox_inches="tight")
```

## 18. 一句话执行原则

正文图片的目标不是“多画几张”，而是让每一项核心结论都能沿着“题目条件—模型机制—真实计算数据—图中证据—适用边界”被评委快速核查；任何没有权威数据支撑的新图宁可暂不生成，也不能用视觉效果补造证据。
