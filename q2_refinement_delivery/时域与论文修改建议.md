# 时域裁定与可直接使用的论文段落

## 1. 最终裁定：保留3小时文件，但不宣称无歧义的数天全程交付

原PDF第二页要求“建立整个烘干过程”的模型，并明确论文只列3h内每0.5h结果；完整逐秒Excel未直接给结束时间。模板和附录1规定单位与布局，但没有提供一个数天终点，因此题面存在需要披露的输出时域解释。

本轮保留现有1—10800s文件：它覆盖论文明确展示时域的全部逐秒状态，属于可解释的工作口径。不能因此声称已经消除“整个过程”措辞的全部歧义，也不能把现有交付称为已经计算到真实干燥结束。

| 层次 | 当前事实或选择 | 严禁扩大的结论 |
|---|---|---|
| 方程适用意图 | 附录3从初态统一使用，不在人为1800s处分段换式 | 方程形式覆盖两阶段，不等于数天初边值问题已经闭合 |
| 外部输入 | 原始241点，0—14400s | 超过4h继续保持任意环境不是测量事实 |
| 论文表 | 0.5、1、1.5、2、2.5、3h | 不能以“2—3天”背景替代真正结束条件 |
| 已验收Excel | 1—10800s，21个半径，453600个结果 | 不叫数天全过程，不自动采用第三问阈值 |
| 本轮新增 | 前3h机制、物理闭合与管理补丁 | 未进行新的长时PDE、达标定位或收缩计算 |

若队伍决定将“完整结果”解释为直至第三问的达标时刻，可以在后续求解统一第三问轨迹后补充更长result2副本；必须明确该停止条件来自第三问，并保持前3h结果一致。本轮不默认采纳该阈值，也不强行选择48或72h。

## 2. 长时扩展之前必须补齐的契约

首先确定4h后T∞与b的延拓方式，其次明确停止规则和输出频率，再选择所需验证。现有数学形式可以写到更长时刻，但当前汇总、Excel审计及论文表约定3h；只修改某个solve_fv的end参数不构成完整长时交付。

尾段均值保持与末值保持只能作为可比较假设，不是观测延长。建议需要长时行为时先只比较这两种环境延拓；均值必须说明样本平均或分段线性输入的时间平均，不能在代码、正文与记录间混用。

|---|---:|---:|
| 原附件最后一条观测 | 50.165000 | 0.04986000 |
| 3—4h的61个样本算术平均 | 49.998934 | 0.04998754 |
| 3—4h分段线性输入的时间平均 | 49.995917 | 0.04999042 |


表中数值由原附件实际重新计算，但三种延拓均未用于本轮新增PDE求解。建议比较关键径向状态、若明确采用的终止时间、总有效失水和边界平衡残差；结论只在所选择的模型与外推假设下成立。

只有确实延伸时，才重新检查低C使D退化、表层分辨率、正值和非线性边界分支，以及长时轴向端部影响。已有3h四位输出、短时边界层和二维对照都不是数天情景的严格误差保证；这不构成当前3h答案的新数值缺陷。

## 3. 可直接插入正文的段落

### 3.1 模型适用范围和变量解释

第二问从初始时刻统一采用附录3，建立固定圆柱中截面的有效热质传输模型。经验ρc_p用于当地有效热容量，含水率按干物质质量归一化；固定参考干密度只用于有效水分守恒解释，不将其同时视为严格真实变密度样品。

外部环境由附件1给定，并以分段线性插值构造输入。题面没有提供空气水分量与药材平衡含水率的关系，故本问采用数值恒等的等效边界映射，并继承交换系数；这是一项闭合假设，而非气固平衡关系已被实测识别。

### 3.2 扩散机制与空间差异

将扩散系数相对初值的对数变化分解为温度项H与含水率项M。3h时轴心、1 cm和表面的D/D₀分别为2.1957、2.1289和1.8207，说明在该轨迹的累积变化中，升温促进大于失水抑制；分解并不表示独立的因果贡献百分比。

表面扩散率在早期短暂降低，随后回升，并在约2.017h取得每秒轨迹的最大值。最后半小时三个位置的温度项仍增加，但含水率抑制更强，D分别净下降1.061%、1.394%、3.160%，体现阶段性竞争。


### 3.3 参数敏感性和验证范围

现有单因素情景表明，3h含水率对hₘ的相对变化比对hT更敏感，但hT对早期温度仍有可见影响。因此应针对输出量和时刻讨论主导参数，而非仅凭一个扩散时间尺度作全局判断；扰动范围为确定性情景，不作置信区间解释。

数值验证支持当前模型、参数和输入下的离散精度，不说明缺失的界面平衡、潜热或携焓机制足够小。真实蒸发模型需要以相同质量通量联合闭合气固平衡和界面能量，并补齐组成热焓与密度基准，不能只追加一个吸热项。

### 3.4 输出时域

本文模型统一描述预热与恒温阶段的有效传输，按题目明确展示要求给出前3h的结果。result2.xlsx保存1—10800s、径向0—2cm每0.1cm的完整逐秒状态；这是对本问Excel时域的工作性解释，不将其称为数天全过程结果。

附件1仅覆盖前4h，进一步求取干燥终点必须明确环境延拓和停止条件，并重新验证长时低含水率与端部影响。本文没有以背景中的2—3天设定固定终点，也没有在第二问结果中默默引入后续问题的收缩数据或停止阈值。

## 4. 正文与支撑材料如何取舍

正文优先保留扩散率比图、H/M表及上述结论；瞬时导数、全时域灵敏度、缓存测试和每次访问记录放支撑材料。不要把本轮审阅过程写成参赛队已完成的人工作业；最终采纳和人工核对仍应由队伍逐项记录。

题给两张温度／含水率结果表不改。若合并到正式论文，应保留Richardson与独立验证的简洁方法说明，不删掉外推后声称原FV2560独自保证全部四位一致；实现和历史核验细节无需占据正文主要篇幅。
