## 复现本轮主要成果

```bash
python -m pip install -r requirements.txt
python source/q2_mechanism.py --out reproduced_analysis
python tests/test_run_guard.py
python tests/check_entry.py
python source/audit_new_delivery.py
```

第一条后处理命令只读取本包的未舍入状态，不求解PDE，在新目录生成全部图／CSV／NPZ。省略--out则更新本包自己的data和figures；它不会重建旧result2.xlsx。`build_review_docs.py`使用本包已生成记录重建评审文稿，变更输入后应重新人工审阅叙述。

`test_run_guard.py`使用临时软件夹具验证缓存与路径规则，并作两次相同60s/40区间核函数比较；`check_entry.py`实际跑新入口的tests阶段并验证resume与拒绝覆盖。两者不是完整3h生产解或本轮全十阶段验收。

可选地，提供原上传包的解压目录，核验191个原文件仍未改变：

```bash
python source/audit_new_delivery.py --handoff /path/to/extracted_handoff
```

完整原敏感性数组不在本包重复分发；本包内轨迹投影足以重现新增分析。需要从原数组重新提取时，可运行prepare_reused.py并显式传入原交付解压目录、此前单独的q2_validation_arrays.zip和新的投影输出目录。

## 数值与物理结论

H+M与ln(D/D₀)在三位置全部样点的最大差为2.803e-15；初始表面先受失水抑制，随后升温占优，晚期又出现净回落。各位置峰值不同，瞬时项可受环境波动而改号，不能据最终D高于初值宣称全过程一直加速。

hₘ和边界平衡映射不可凭外部输入独立识别；没有本药材的气固平衡、真实失重和组成热焓，不能给唯一相变修正值。保留有效容量方程，不直接把它改成无配套携焓的乘积导数，不把相邻扩散引起的C_t当局部蒸发率。

现有Excel仍为1—10800s。方程意图覆盖预热／恒温，并不等于数天输入和停止规则已经闭合；长时研究需单独采用环境延拓、终止规则和相应验证。本轮未求第三问结束时刻或第四问收缩。
