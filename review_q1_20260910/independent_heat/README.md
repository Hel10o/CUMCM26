# 第一问温度独立复算

复算范围：复核交付文件采用的**中截面一维径向、常物性、不含潜热、环境分段线性插值模型**的数值答案。复算通过仅说明该模型求解正确，不独立证明忽略端部和潜热的物理假设。

本目录脚本不导入交付目录任何求解、验证或 Excel 读取函数；直接读取原始 `A题/附件/附件1.xlsx` 的 OOXML 数据。最后才读取交付的 NPZ 和 Excel 作比较。

设环境温度为 E(t)，温差 θ=T−E，热扩散率 α=0.36/(820×2600)，Bi=25×0.02/0.36。独立采用如下解析展开：

```text
θ_t = α(θ_rr + θ_r/r) − E'(t)
θ_r(0,t) = 0
θ_r(R,t) + (h/k)θ(R,t) = 0
β_n J1(β_n) = Bi J0(β_n)
b_n = 2J1(β_n) / [β_n(J0(β_n)^2+J1(β_n)^2)]
q_n = α β_n^2/R^2
θ(r,t) = Σ a_n(t) J0(β_n r/R)
a'_n + q_n a_n = −b_n E'(t), a_n(0)=0
```

附件的温度节点均为整数秒，因此每个 1 s 区间上的斜率 s 恒定，可用解析递推直接推进，无时间离散误差：

```text
a_n(t+1) = exp(−q_n)a_n(t) − b_n s [1−exp(−q_n)]/q_n
```

分别取 200、800、3200 个特征模态检查截断收敛，并核对全部 1800×21 个温度结果及表 1 的 7×5 个结果。四位小数比较独立使用 Python `format(value, '.4f')`，与交付要求一致。

运行命令（在项目根目录）：

```powershell
& review_q1_20260910/.venv/Scripts/python.exe -X utf8 review_q1_20260910/independent_heat/independent_heat.py
```

- 3200 模态与交付未舍入温度的最大绝对差为 `7.290214654176452e-9 ℃`，位于 `t=300 s, r=2 cm`；均方根误差为 `1.6333273759618696e-9 ℃`。
