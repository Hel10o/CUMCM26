## 最小复核命令

在本目录执行（需要Python、numpy、scipy、artifact_tool；不依赖网络）：

```bash
PYTHONDONTWRITEBYTECODE=1 python source/review_checks.py --out validation/review_checks_rerun.json
```

Windows PowerShell可直接运行 `python source/review_checks.py --out validation/review_checks_rerun.json`。脚本默认拒绝覆盖同名输出，仅读取来源；`given_model.py`只含物性/边界接口，缺平衡映射时主动报错，不是整套PDE求解器。
